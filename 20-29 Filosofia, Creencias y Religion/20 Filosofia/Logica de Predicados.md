# Logica de Predicados
Los **predicados** son estructuras que forman una aseveración al ser aplicadas a un sujeto. Un sujeto puede ser una entidad concreta o ser un cuantificador. El **cuantificador universal** se usa para indicar que un predicado es verdadero para todos los elementos de un conjunto. El **cuantificador existencial** expresa que un predicado es verdadero para al menos un elemento de un conjunto. Los predicados, al igual que las aseveraciones, pueden ser simples o compuestos. Para Evaluar la validez de un argumento, se debe considerar que si una aseveración universal es verdadera, su predicado se instancia para cual entidad. Una aseveración existencial verdadera se instancia al menos una vez.
